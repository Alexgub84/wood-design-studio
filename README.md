# אומן העץ — Wood Design Studio Site

Personal portfolio website for a Hebrew-speaking wood/industrial designer.

## Tech Stack
- Astro 4.x
- Tailwind CSS 3.x
- TypeScript
- Hebrew (RTL)

## Quick Start
```bash
npm install
npm run dev
```

Open http://localhost:4321

## Sections
- Hero — Full bleed intro with tagline
- About — Designer background and stats
- Services — What's offered
- Gallery — Portfolio of projects
- Process — How to work together
- Testimonials — Customer quotes
- Contact — Form + WhatsApp

## Deploy
Works with Vercel, Netlify, or any static host.
```bash
npm run build   # outputs to dist/
```
